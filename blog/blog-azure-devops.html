Blue-green with Bicep: resilient delivery on Azure DevOps

June 12, 2024 Azure • Bicep • Multi-stage pipelines

This experiment set out to build confidence in Azure DevOps by applying production patterns to a learning project. The focus: blue-green deployments powered by Bicep templates and controlled through staged approvals.

Composing infrastructure with Bicep

Bicep templates define the full stack — resource groups, app service plan, web app, networking rules, and diagnostics. Parameters allow me to promote the same artefacts across environments without rework.

Multi-stage delivery with guard rails

The pipeline compiles Bicep to ARM, validates templates, then creates two identical environments (blue/green). Manual approvals sit between staging and production to simulate real-world change control. Traffic switching happens via Azure Front Door routing rules.

Testing rollback scenarios

By re-running the pipeline with intentionally failing builds, I validated rollback behaviour — the previous environment stays healthy while the failed slot is automatically isolated. Logging through Application Insights confirmed zero downtime deployments.

The outcome is a confidence boost in orchestrating Azure resources with code while respecting enterprise-style governance. It also opened doors to expand the pattern with automated security scans and policy checks.
